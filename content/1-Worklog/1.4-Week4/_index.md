### Week 4 Objectives:

- Understand AWS monitoring and observability services.
- Learn security best practices and the principle of least privilege.
- Explore AWS Systems Manager for resource management.
- Understand Continuous Integration and Continuous Delivery (CI/CD).
- Learn how to monitor and optimize AWS costs.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| 2 | Learn Amazon CloudWatch, including Metrics, Logs, Dashboards, and Alarms. Practice monitoring EC2 CPU utilization and creating an alarm. | 26/10/2026 | 26/10/2026 | https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.html |
| 3 | Study AWS security services and practices, including IAM policies, Least Privilege, AWS KMS, and AWS Secrets Manager. | 27/10/2026 | 27/10/2026 | https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html |
| 4 | Explore AWS Systems Manager, including Session Manager and Run Command. Understand how to manage EC2 instances without direct SSH access. | 28/10/2026 | 28/10/2026 | https://docs.aws.amazon.com/systems-manager/latest/userguide/what-is-systems-manager.html |
| 5 | Learn CI/CD concepts and explore AWS CodePipeline, CodeBuild, and GitHub Actions. Understand the basic application build and deployment workflow. | 29/10/2026 | 29/10/2026 | https://docs.aws.amazon.com/codepipeline/latest/userguide/welcome.html |
| 6 | Study AWS cost optimization, AWS Budgets, and AWS Pricing Calculator. Review unused resources and summarize the week's knowledge. | 30/10/2026 | 30/10/2026 | https://calculator.aws/ |

### Week 4 Achievements:

*To be updated after completing the planned learning activities and hands-on practices.*

Expected outcomes:

- Monitor EC2 resources using Amazon CloudWatch.
- Understand Metrics, Logs, Dashboards, and Alarms.
- Apply IAM security best practices and Least Privilege.
- Understand AWS KMS and Secrets Manager.
- Use AWS Systems Manager to manage EC2 instances.
