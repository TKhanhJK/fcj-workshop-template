### Week 3 Objectives:

- Understand AWS storage services and their use cases.
- Learn how to create and manage Amazon S3 buckets.
- Understand relational databases and Amazon RDS.
- Learn how EC2 instances communicate with RDS databases.
- Explore basic application and database migration concepts.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| 2 | Learn Amazon S3 concepts, including buckets, objects, storage classes, versioning, and bucket policies. Practice creating a bucket and uploading files. | 19/10/2026 | 19/10/2026 | https://cloudjourney.awsstudygroup.com/vi/ |
| 3 | Study Amazon RDS, database engines, DB instances, backups, and database security. Explore the process of creating an RDS instance. | 20/10/2026 | 20/10/2026 | https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Welcome.html |
| 4 | Learn how to connect an EC2 instance to an RDS database within a VPC. Understand Security Group configurations and database connectivity. | 21/10/2026 | 21/10/2026 | https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/CHAP_Tutorials.html |
| 5 | Explore AWS storage and migration concepts, including EBS, EFS, snapshots, and application migration strategies. | 22/10/2026 | 22/10/2026 | https://cloudjourney.awsstudygroup.com/vi/ |
| 6 | Review the week's knowledge and practice an architecture combining EC2, S3, and RDS. Review resource permissions and estimated costs. | 23/10/2026 | 23/10/2026 | https://aws.amazon.com/architecture/ |

### Week 3 Achievements:

*To be updated after completing the planned learning activities and hands-on practices.*

Expected outcomes:

- Understand the differences between Amazon S3, EBS, and EFS.
- Create and manage Amazon S3 buckets and objects.
- Understand Amazon RDS and relational database concepts.
- Understand how EC2 communicates with RDS within a VPC.
- Design a basic AWS architecture using EC2, S3, and RDS.
