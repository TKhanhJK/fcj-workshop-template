### Mục tiêu tuần 5:

- Hiểu về mô hình điện toán không máy chủ (Serverless Computing) trên AWS.
- Học cách tạo và thực thi các hàm AWS Lambda.
- Hiểu cách Amazon API Gateway quản lý và cung cấp các điểm cuối ứng dụng (endpoints).
- Khám phá kiến trúc hướng sự kiện (event-driven architecture) sử dụng Amazon SQS và Amazon SNS.
- Nắm vững kiến trúc Microservices và các khái niệm về hệ thống phân tán.
- Xây dựng kiến trúc ứng dụng Serverless cơ bản.

### Kết quả đạt được tuần 5:

*Sẽ cập nhật sau khi hoàn thành các hoạt động học tập và bài thực hành đã đề ra.*

Kết quả kỳ vọng đạt được:

- Nắm vững mô hình Serverless Computing trên nền tảng AWS.
- Tạo và kiểm thử thành thạo các hàm AWS Lambda cơ bản.
- Hiểu rõ cơ chế API Gateway xử lý và điều hướng các HTTP requests.
- Phân biệt rõ sự khác nhau giữa dịch vụ hàng đợi Amazon SQS và dịch vụ thông báo Amazon SNS.
- Phân biệt sự khác nhau giữa kiến trúc Monolithic và kiến trúc Microservices.
- Thiết kế được một ứng dụng Serverless cơ bản kết hợp API Gateway và Lambda.
