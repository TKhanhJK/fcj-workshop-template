### Week 5 Objectives:

- Understand the Serverless Computing model on AWS.
- Learn how to create and execute AWS Lambda functions.
- Understand how Amazon API Gateway exposes application endpoints.
- Explore event-driven architecture using Amazon SQS and SNS.
- Understand Microservices and distributed system concepts.
- Build a basic serverless application architecture.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |

| 3 | Study Amazon API Gateway, including REST APIs, HTTP APIs, endpoints, requests, and responses. Explore integrating API Gateway with Lambda. | 03/11/2026 | 03/11/2026 | https://docs.aws.amazon.com/apigateway/latest/developerguide/welcome.html |
